# Raw Source Materials

This directory is intentionally kept out of Git for complete source texts.

Do not commit full ebooks, scans, OCR dumps, or large copyrighted excerpts here. Keep complete source materials in a private, access-controlled location outside the repository, and use `knowledge/AGENTS.md` to register source IDs that can be referenced by synthesized wiki pages.

Allowed in Git:

- this README
- short source metadata or manifests that do not include copyrighted body text
- notes about licensing, permission, or public-domain status

Not allowed in Git:

- full `.epub`, `.pdf`, `.md`, `.txt`, or OCR copies of copyrighted books
- large verbatim excerpts
- files derived from ebooks that preserve substantial original expression
